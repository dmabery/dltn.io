A new CMS.

A great thing about having a blog that is statically generated is that all of the content, design, and information is yours to customize. The only limit is your technical ability, and with Claude Code that is no longer really a limit.

But the downside is writing markdown files. It is hard and annoying to write markdown files in a text editor.

But [PagesCMS](https://pagescms.org/docs/configuration/fields/select/) looks dope.
